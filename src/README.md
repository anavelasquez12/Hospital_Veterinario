Momento 2, Evaluación POO Hospital Veterinario

¿Que se hizo?

- Construi un sistema de consola por comandos para gestionar pacientes (su estado y datos individuales)
- La asignación de jaulas para cada tipo de paciente, sea perro, gato o ave exotica
- Realice también los reportes en consola detallados, contiene el conteo de los pacientes, su estado actual y el número de pacientes con el que cuenta la clinica

¿Como lo hizo?

- El proyecto lo realice bajo las reglas de la actividad (ademas con el uso de IA)
- No se utilizaron ArrayList
- Hay Herencia
- Todos los atributos de los objetos son private, su acceso y modificación se realiza exclusivamente a través de métodos get y set, incorporando validaciones de seguridad en los modificadores para evitar la inyección de datos inválidos o corruptos.
